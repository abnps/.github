# Sigurnost · Security

Ako nađeš sigurnosni problem u nekom od naših programa (npr. u vezi programa s browserom ili u ažuriranju),
**nemoj ga prijaviti javno**. Pošalji opis na **abnpsdev@gmail.com** s naslovom „Sigurnost".
Odgovaramo u roku od nekoliko dana i javno objavljujemo ispravku tek kad je izdanje spremno.

*If you find a security issue in one of our programs (for example in the browser connection or in updates),
**please don't report it publicly**. Send a description to **abnpsdev@gmail.com** with the subject "Security".
We reply within a few days and publish the fix once a release is ready.*

Podržana je samo najnovija verzija. · *Only the latest version is supported.*
